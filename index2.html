20 Common HTML Tags with Examples

HTML Tags

HTML Tags

1. <html> Tag

Defines the root of an HTML document.

<html> Content </html>

2. <head> Tag

Contains information about the webpage.

<head> ... </head>

3. <title> Tag

Defines the title displayed on the browser tab.

<title>My Website</title>

4. <body> Tag

Contains all the visible content of a webpage.

<body>Hello World</body>

5. <link> Tag

Connects an external CSS file to an HTML document.

<link rel="stylesheet" href="style.css">

6. Heading Tags

HTML provides six levels of headings from h1 to h6.

Heading 1

Heading 2

Heading 3

<h1>Heading</h1>

7. <b> Tag

Displays text in bold.

This is bold text. <b>Bold Text</b>

8. <span> Tag

Used to style or group a small part of text.

This is span text inside a paragraph.

<span>Text</span>

9. <br> Tag

Creates a line break in the webpage.

Hello
Welcome to HTML <br>

10. <address> Tag

Displays contact information.

Haripriya
Coimbatore, Tamil Nadu
<address>Contact Information</address>

11. List Tags

Used to create ordered and unordered lists.

  • HTML
  • CSS
  • JavaScript
  1. First
  2. Second
<ul> <li>Item</li> </ul>

12. <details> Tag

Creates expandable content.

Click here

This content appears when the details section is opened.

<details>...</details>

13. <summary> Tag

Defines the visible heading inside a details element.

What is HTML?

HTML stands for HyperText Markup Language.

<summary>What is HTML?</summary>

14. <img> Tag

Displays an image on a webpage.

<img src="image.jpg" alt="Image">

15. <audio> and <video>

Used to add audio and video to a webpage.



<audio>...</audio> <video>...</video>

16. <table> Tag

Creates a table for displaying data.

Name Course
Haripriya MCA
Student BCA
<table>...</table>

17. <form> Tag

Creates a form for collecting user information.



<form>...</form>

18. <label> and <button>

Label describes an input and button creates a clickable button.



<label>Name</label> <button>Click Me</button>

19. Structural Tags

These tags help organize webpage content.

Header
Home

This is a section.

This is a div.
Footer
<header> <nav> <section> <div> <footer>

20. <a> and <script>

The a tag creates hyperlinks and the script tag adds JavaScript.

Visit Google

<a href="...">Link</a> <script>...</script>
